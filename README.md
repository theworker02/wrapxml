# wrapxml

Wrap CSV/TSV xml tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/wrapxml/

## Install / run

```bash
git clone https://github.com/theworker02/wrapxml.git
cd wrapxml
node src/cli.js
node --test
```
